# One Page Report Coin Submission Framework

Source: https://www.skool.com/coinpicksgenesis/classroom/eed2ad74?md=b2fbc0fc45b0458cb2886e5d0acadc0c

## What This Is

The deliverable template. Every researched coin produces one of these.

Submit to Skool community as a post titled: `COIN RESEARCH SUBMISSION: $TICKER NAME`

---

## Required Sections

### Header
- Project name + ticker (e.g., `Coin: Sogni AI ($SOGNI)`)
- Official CoinGecko link (CMC only if no Gecko page exists)
- One-sentence project overview (no hype, no history, just *what it is*)

### Exclusivity "WOW" Factor
- The single innovation that changes everything
- Concrete comparisons or your own test results where possible
- Must pass before everything else — if it fails, drop the project

### Overview
- 1 plain-language sentence + optional 1-sentence analogy (e.g., "Like Render's front-end" / "GitHub + Kickstarter for science")

### Liquidity
- Tier: **Low / Medium / High**
- Link to largest DEX liquidity pool (GeckoTerminal)
- Brief justification using ±2% depth + pool TVL

### Narrative Scoring (/31)
Six sub-scores, each with 1–2 sentence explanation + source links with Ctrl+F quotes:

1. **Narrative Maturity (0–7)** — how far along is the narrative in the cycle?
2. **Smart Money Compatibility (0–6)** — would serious capital flow in?
3. **Hair-on-Fire Innovation (0–6)** — urgent, painful problem being solved?
4. **Narrative Communication (0–5)** — how well is the story being told?
5. **Narrative Lineage (0–4)** — connected to a previously proven 100x trend?
6. **Narrative Mutation (0–3)** — evolved into a real-world trend?

### Team Analysis
3–5 key people, in this order: Founder → Head of Product → Head of Marketing → optional standouts → advisors (only if world-class).

For each:
- **One-sentence summary** of past experience (NOT the current project) citing **financial metrics first**, **adoption metrics second**, both with sourced Ctrl+F quotes
- Grade: `H/5 + M/3 + L/2 = X/10`

### CoinPicks Grade (Final)
- Narrative total: `X / 31`
- Team weighted score: `(Founder × 5 + sum of others) ÷ (5 + N_others) = X.XX / 10`

### Extras (optional but encouraged)
- Risk notes (e.g., liquidity halving incidents)
- Bonus narrative tailwinds (high-signal tweets, competitor moves)

---

## Style Rules

- **Sources with Ctrl+F quotes:** every claim that isn't trivially obvious needs a real link and an exact-text snippet to Ctrl+F on that page.
- **No AI-only reports:** if you can't explain it at a deep level, it gets rejected.
- **One-sentence team summaries:** if you can't say it in one sentence, you don't understand it yet.
- **Past metrics, not current project:** team credibility is from prior wins, not the project being researched.
- **Quality over quantity:** the Product/Exclusivity filter should reduce the pile, not grow it.

---

## Submission Order

1. Run Exclusivity Factor test → if fails, kill project
2. Create Skool post with title format
3. Attach PDF of the one-pager
4. Fill in body sections in order: Strategy → Liquidity → Narrative → Team → Final Grade
